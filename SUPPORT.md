# Getting help

- **Installing or using Mentat:** start with [INSTALL.md](INSTALL.md) and the
  [usage guide](reference/usage.md). Your agent can also explain itself: ask it "how do you work?".
- **A question:** ask in [Discussions (Q&A)](https://github.com/lipi4242/mentat/discussions/categories/q-a).
- **Something is broken:** open a bug report (the form asks what we need), or ask your agent to
  draft one for you with its `bug-report` skill. See [CONTRIBUTING.md](CONTRIBUTING.md).
- **A security problem:** privately, never in public. See [SECURITY.md](SECURITY.md).

This is a small project: answers usually come within a few days.
