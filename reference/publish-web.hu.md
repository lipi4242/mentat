# Netre kitétel nem technikai FELHASZNÁLÓNAK

Akkor olvasd, ha a FELHASZNÁLÓ azt kéri, hogy a munka (lista, kis alkalmazás) a neten vagy a telefonján is elérhető legyen. Az alap-út: **Cloudflare Worker + D1 (vagy KV) a `*.workers.dev` címen, Cloudflare Access védelemmel.** Domain nem kell, a FELHASZNÁLÓNAK parancsot futtatnia nem kell; a parancsokat te futtatod.

Tilos: alagút vagy VPN a FELHASZNÁLÓ gépéről (trycloudflare, ngrok, Tailscale Funnel/Serve), a gép kitétele a netre, saját jelszó/login-oldal/basic auth, titkos vagy hosszú URL mint védelem, `wrangler login` fejetlen gépen, a token a chatben, a `wrangler.toml`-ban vagy a gitben.

## Lépések (egyszerre egy-két képernyő, valós menünevekkel)

Az élesítés a FELHASZNÁLÓ döntése: csak akkor élesíts (deploy), ha kérte, vagy kifejezett igent mondott; addig helyben építs és próbálj. Élesítés és ellenőrzés: `.mentat/bin/mentat_web.py` (a telepítő hozza). Minden kész-jelentés kimondja, hogy élesben van-e (és melyik címen), vagy csak helyben fut.

1. **Fiók:** dash.cloudflare.com → Sign up → e-mail-megerősítés. Ha van fiókja, csak belép.
2. **Token** (eszközzel): egyszer töltsd le az eszközöket: `curl -fsSL --create-dirs -o '.mentat/bin/web/#1' 'https://raw.githubusercontent.com/lipi4242/mentat/v0.6.0/reference/web/{cf_api.py,mentat_cf_access.py,mentat_cf_token.py,mentat_cf_need.py}'`, aztán futtasd: `python3 .mentat/bin/web/mentat_cf_token.py next`, és az EGY lépését add tovább (üzenetenként egy-két lépés), várd meg a „kész”-t, futtasd újra, amíg azt nem mondja: ready. A sablont követi (My Profile → API Tokens → az **Edit Cloudflare Workers** sablon a Workers Scripts · Edit és az Account Settings · Read sorral; a meglévő sor szintjét állítja Read → Edit, új sort csak akkor ad hozzá, ha nincs; a D1 és az Access: Apps and Policies Edit), és minden lépés után ellenőriz; a `--check` a tokent és minden jogot ellenőriz.
3. **Hova másolja:** az eszköz létrehozza a `.env`-et (0600, `.gitignore`-ban); a FELHASZNÁLÓ rejtett helyi űrlapba illeszti (`mentat_serve.py --secret`). Chatbe írta: azonnal `mentat_secret.py put CLOUDFLARE_API_TOKEN`, soha ne írd vissza.
4. **Fiók-azonosító:** az eszköz a `.env`-be írja a `CLOUDFLARE_ACCOUNT_ID`-t, amikor ready.
5. **Tárhely és deploy:** minden lépés `mentat_web.py deploy --approved "<az igenje>" [--url <cím>] -- <parancs>` úton: `npx wrangler d1 create <név>` → kötés a `wrangler.toml`-ba (az azonosító nem titok); séma: `npx wrangler d1 migrations apply <név> --remote`; végül `npx wrangler deploy`. A cím `https://<worker>.<fiók>.workers.dev`.
6. **Ha 10000-es hiba jön** (Authentication error): a tokenből hiányzik egy jog; a hibás parancsból tudod, melyik (`d1 …` → D1, `kv …` → Workers KV Storage, `deploy` → Workers Scripts). Mondd meg pontosan: My Profile → API Tokens → a token sorában … → Edit → a hiányzó sor legyen **Edit** → Continue to summary → Update token. A token értéke ugyanaz marad. Utána ugyanazt a műveletet futtasd újra. Ne kerüld meg más tárhellyel vagy helyi futtatással.
7. **Védelem** (eszközzel, nem gombokkal): `python3 .mentat/bin/web/mentat_cf_access.py ensure --worker <worker> --email <a FELHASZNÁLÓ e-mailje> [--email …]`. Idempotens; `check --worker <worker>`: be van-e kapcsolva; a 2-es kód a hiányzó token-jogot nevezi meg (6. lépés). Védelmet az Access ad, a worker sajátot nem. Hogy ki van bejelentkezve: `ctx.access`; teljes JWT-ellenőrzés csak beállított `POLICY_AUD` és `TEAM_DOMAIN` mellett, különben minden kérés 403. Élesítés előtt: bejelentkezve (böngésző vagy `CF_Authorization` süti) 200 és az adat, anélkül a belépőoldal: `mentat_web.py check <cím> --cookie-file <fájl>` OK-t ír. Ha azt mondja, „nem kell jelszó”, előbb mondd el, hogy nélküle bárki látja az adatot, és kérdezz.
8. **Adat:** a teljes, tisztított, visszaolvasott lista menjen fel (nem a nyers fájl); ami gyanús vagy lezárt, az egy állapot mező, nem szűrés. Feltöltés előtt egyeztess: hány tétel megy fel, mi kimaradt vagy mit összevontál, és miért. SQL-fájl → `npx wrangler d1 execute <név> --remote --file …`.
9. **Próba:** az első élesítés után a FELHASZNÁLÓ szemével, bejelentkezve (nem a nyers címen): `mentat_web.py check <cím> --cookie-file <fájl> --contains <tételszám>`; csak utána mondd késznek.
10. **Későbbi változás:** előbb mentés (`npx wrangler d1 export <név> --remote --output …`), aztán migráció (`ALTER TABLE`, új fájl a `migrations/`-ben), aztán deploy. Új adatbázist ne hozz létre, a régi adatot ne töltsd újra.

A Mentat Admin (`admin/`, teendő + backlog) akkor való, ha a FELHASZNÁLÓ a teendőit, ügyeit, backlogját kezelné benne: e-mail-belépése van, ehhez levelező-domain kell. Egy egyszerű listához ez az út.
